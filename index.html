Caspian Privacy Policy

Privacy information for the Caspian browser extension

Last updated: 16 October 2026

Caspian helps users listen to readable webpage and PDF content with speech playback, reading controls, and saved reading progress. This policy explains what information the extension accesses, how it is used, and the choices available to users.

Information Caspian accesses and stores

  • Webpage and PDF content: When a user starts a reading feature, Caspian accesses readable text from the active page or PDF so it can provide speech playback, reading navigation, and spoken-text highlighting.
  • Page details and reading progress: Caspian may save page URLs, page or document titles, reading positions, and items in a saved reading queue so users can resume a reading session.
  • Preferences: Caspian stores extension settings such as reading and voice preferences.
  • Temporary session information: The extension may keep current playback state and queue information in browser session storage while a reading session is active.
  • Microphone and speech recognition: The submitted code includes microphone and browser speech-recognition functionality for dictation. If this functionality is activated, the extension may request microphone access and receive speech-recognition results. The browser or its speech-recognition provider may process audio or speech data under that provider's own terms. Do not assume audio is processed only on-device; this can depend on the browser and provider.

How information is used

The information described above is used to provide Caspian's reading, playback, navigation, highlighting, saved-progress, settings, and any enabled speech-recognition features. Caspian is not intended to use this information for advertising, profiling, selling data, or determining creditworthiness.

Where information is stored and shared

Reading preferences, saved reading details, and reading progress are stored using the browser's extension storage on the user's device. The extension package reviewed for this policy did not show a Caspian-operated analytics or transcription endpoint. However, browser-provided speech-recognition or text-to-speech services may process information according to the browser, operating system, voice engine, or service selected by the user. Those providers have their own privacy terms and practices.

Caspian's developer does not sell user data. User information is not shared by the developer with advertising networks or data brokers. If a future version adds a server, analytics, cloud sync, or another third-party integration, this policy must be updated before that version is released.

Permissions

Caspian uses browser permissions to provide its features. Depending on the feature used, these can include access to the active tab, scripts for reading and highlighting page text, extension storage, tab information, an offscreen document for supported background processing, and browser text-to-speech. Optional website access may be requested where required for a feature. Microphone access is relevant only to speech-recognition functionality when invoked.

Retention and deletion

Information saved in extension storage remains until it is removed by the extension, cleared by the user, or deleted when the extension's data is cleared or the extension is uninstalled. Temporary session data is intended to support the current browser session. Users can stop using Caspian at any time and can clear the extension's stored data through the browser's extension/site data controls. Exact controls may vary by browser version.

Security

Caspian is designed to use browser extension storage and browser-provided APIs for its core features. No software can guarantee absolute security. Users should keep their browser updated and avoid using extensions on pages or with information they do not want processed by the relevant browser features or speech providers.

Children's privacy

Caspian is a general-purpose browser extension and is not designed specifically to collect personal information from children.

Changes to this policy

This policy may be updated when Caspian's functionality, permissions, or data practices change. The latest version will be published at this URL, with the updated date shown near the top.

Chrome Web Store Limited Use

Caspian's use and transfer of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only as needed to provide the extension's disclosed user-facing features, and is not sold or used for personalized advertising.
